# Canonical authored vault

This vault now contains **Bray Core Corpus v0.1**, the first production case corpus for the Interrogation System.

Canonical authored material is Markdown + YAML frontmatter. Generated JSON in `dist-data/` is never canonical.

The corpus currently covers:
- ITD / near-field claims
- 4940 Hz / Strouhal / ballistic-gel attribution
- PCB color and dimensional identity claims
- radial optical-flow / pressure / energy claims
- first-audio timing limitations
- RØDE acoustic classification vs the 0.5 g PETN shaped-charge social model
- medical-analysis limitations and the later "13 of 13" shaped-charge synthesis

Preserved source artifacts live under `public/evidence/bray/` and are hashed by source nodes.
The social-media screenshots use visually reviewed image-region receipts; the compiler does not OCR-verify those receipts.
