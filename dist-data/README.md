# Generated production artifacts

The Slice 2 zero-node production JSON was moved to `docs/slice-2-empty-dist-data/` when Bray Core Corpus v0.1 was authored.

Run:

```sh
npm run compile
```

to compile the canonical `vault/` into current production `graph.json`, `provenance.json`, `diagnostics.json`, and `build-manifest.json`.

Generated JSON is never canonical.
